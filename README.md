# 바로GO — 강남 출장마사지·홈타이 안내 사이트

서울 강남구 전지역 방문 관리(출장마사지·홈타이) 안내용 정적 사이트입니다.
예약전화: **0508-202-4719**

## 구조

- 정적 HTML 사이트 — 어느 호스팅(GitHub Pages, Netlify, 일반 웹서버)에서든 그대로 서빙 가능
- `build.py` + `content/` 패키지에서 페이지를 생성하는 빌드 방식
- 생성물(각 디렉터리의 `index.html`, `sitemap.xml`, `robots.txt`)도 저장소에 포함

```
build.py            # 빌드 스크립트 (레이아웃·글자수 검사·디스크립션 80자 검사·sitemap)
content/
  site.py           # 상호(바로GO)·전화·BASE_URL·메뉴(NAV)
  main.py           # 메인 페이지 (+ WebPage/BreadcrumbList/Organization/FAQPage JSON-LD)
  areas.py          # 대표 행정동: 강남구 허브 + 대표 동 12개
  stations.py       # 지하철역: 허브 + 역 14개(그룹 A)
  stations2.py      # 지하철역: 역 13개(그룹 B)
  districts.py      # 생활권: 허브 + 생활권 9개
  themes.py         # 테마별 안내: 허브 + 테마 14개
  info.py           # 출장마사지 안내·코스·예약·가이드·후기·고객센터·약관
  magazine.py       # 매거진 허브 + 아티클 (Article JSON-LD)
  about.py          # 운영자 소개 (E-E-A-T)
  pricing.py        # 공용 요금 블록
assets/             # CSS, 모바일 내비 JS, 파비콘/OG 이미지
```

## 페이지 구성 (스펙 54 + 템플릿 확장)

- 메인 1 (루트 `/`)
- 대표 행정동 12 — 신사·압구정·청담·논현·삼성·역삼·대치·도곡·개포·일원·수서·세곡동
- 지하철역 27 — 강남역·역삼역·선릉역·삼성역·수서역 등 (환승역 포함 역명 1URL)
- 생활권 9 — 강남역 생활권·테헤란로·코엑스·청담압구정·논현학동·대치학원가·도곡개포·수서·세곡자곡
- 안내/지원 — 예약·이용가이드·홈타이 가이드(코스)·후기·고객센터·개인정보·약관
- 확장 — 테마별 안내 14, 매거진, 운영자 소개

## 빌드

```bash
python3 build.py
```

빌드 시 페이지별 본문 글자수와 디스크립션 글자수 리포트가 출력됩니다.

## SEO 운영 원칙 (빌드에 강제됨)

- **메타 디스크립션은 80자 이내** — 초과 시 빌드 리포트에 경고 출력
- 본문 **2,000자 미만 페이지는 자동 `noindex`** 처리되고 sitemap에서 제외
- 대표 행정동만 운영 — 번호 행정동(논현1·2동, 삼성1·2동, 개포1~4동 등) 개별 페이지 없음
- 역은 역 1개당 페이지 1개 — 환승역(강남·선릉·수서 등)도 URL 하나, 노선별·출구별 페이지 없음
- **지역+역+테마 조합 페이지 없음** (도어웨이 방지) — 테마는 독립 페이지로만 운영
- 인접 타 구 성격 역(양재역·고속터미널역 등)은 강남 단독 페이지를 만들지 않음
- 상단/하위 메뉴와 푸터에 키워드·지역명·역명 대량 나열 없음
- 모든 페이지 본문은 페이지별 고유 작성 (지역명만 바꾼 복붙 없음)
- 방문형 사이트로 오프라인 주소가 없어 **LocalBusiness Schema 미사용** (Organization 사용)

## 배포 전 해야 할 일

1. `content/site.py`의 `BASE_URL`을 실제 도메인으로 변경
2. `python3 build.py` 재실행 (canonical·sitemap·robots.txt에 반영됨)
3. Google Search Console에 `sitemap.xml` 제출
